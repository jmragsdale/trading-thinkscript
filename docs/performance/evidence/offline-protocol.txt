# Frozen event-study protocol (written before outcomes)
MACD-V: 1m, default detector, futures scanner price gate removed explicitly; original price gate counted separately. NShape: default quant-filtered 1m afternoon longs; futures transfer experimental, no absolute share-volume gate. Wick sweeps: 15m, default settings, newest zone per side, strict sweep, age 1–49, no rejection requirement.
All events confirmed at signal close; measurement entry next bar open, directional terminal close and MFE/MAE across 1/3/5/10 bars. Event horizons are not executable trading rules. MNQ point value $2, 0.25pt slippage per side + $0.74 fee per side ($2.48 round trip); SPY underlying proxy 0.02/share round-trip, no options inference. Also report double costs.
MNQ outright quarterlies only. Front contract selected using previous ET date total volume, never current date future volume. Reset indicators on selected contract change. Reject outcomes crossing a contract change, calendar date, or missing elapsed minute. RTH signal/entry/outcome only. Full-session history retained for detectors. Minimum 250 bars warmup per contract segment. SPY uses loaded session history including extended hours, matching code's calendar VWAP rather than claiming RTH-only parity.
Primary de-overlap: per detector/side retain first event then require >10 signal bars separation (non-overlapping outcome windows). Show raw counts. Baselines: same instrument/aggregation/side, unconditional and year × 30-minute signal-time bucket × EMA200 side; all eligible closed bars, same costs/endpoints. Regime: EMA200 side and ATR above/below trailing 100-bar median. Report years and regimes without optimized selection. Day-block bootstrap 95% CI for matched excess, 500 fixed-seed resamples; exploratory across 3 families × 4 horizons × instruments, no corrected discovery claim. No prop pass probabilities, risk strategy sweep, or invented management.
