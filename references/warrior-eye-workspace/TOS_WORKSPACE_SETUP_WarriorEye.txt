STEP-BY-STEP WORKSPACE BUILD
========================================

PART 1: CREATE THE MAIN TRADING WORKSPACE
------------------------------------------

1. OPEN THINKORSWIM
   - Launch TOS Desktop (not mobile/web)
   - Go to Setup → Application Settings → Startup
   - Uncheck "Reuse saved workspace on startup" (for now)
   - Click OK

2. CREATE NEW WORKSPACE
   - Top menu: Setup → Open Shared Item → Search "blank"
   - Or: Setup → Save Workspace As → Name: "WarriorEye_Trading"
   - This gives you a clean slate

3. SET UP TOP PANEL - SCANNER + WATCHLIST (30% height)

   A. ADD STOCK SCANNER
      - Go to: MarketWatch → Stock Hacker
      - Dock it at the TOP of screen
      - Resize to about 30% of screen height

      SCANNER CONFIGURATION:
      □ Click "Scan in: All Stocks" dropdown
      □ Select timeframe: "5 min" (or "1 min" for faster signals)
      □ Click "+ Add Filter"
      □ Select: Custom Study Filter → Study: Custom...
      □ Paste your WarriorEye_Hybrid_DayTrading_Scanner code
      □ Name it: "WARRIOR EYE HYBRID - Day Trading Scanner"
      □ Click OK

      COLUMNS TO ADD (create custom columns):
      1. BuySignal - Show which stocks have entry signal NOW
      2. Quality - Pattern quality score (0-15)
      3. %Change - Percent gain today
      4. RelVol - Relative volume ratio
      5. Volume - Current volume
      6. Price - Last price
      7. RiskReward - R/R ratio for setup
      8. Bars - Days/bars in pullback

      SORT ORDER:
      - Primary: BuySignal (descending) - signals at top
      - Secondary: Quality (descending) - best quality first

      AUTO-REFRESH SETTINGS:
      - Right-click scanner header
      - Select "Auto-refresh"
      - Set interval: "30 seconds" (balance speed vs server load)

   B. ADD WATCHLIST (next to scanner)
      - Right-click in scanner area → Detach to new window
      - Or: Click "Watchlist" tab if combined
      - Create custom watchlist: Name "WarriorEye_Daily"

      WATCHLIST COLUMNS:
      1. Symbol
      2. Last Price
      3. Net Change
      4. % Change
      5. Volume
      6. Relative Volume (custom)
      7. MA9 (custom - SimpleMovingAvg(close, 9))
      8. MA20 (custom - SimpleMovingAvg(close, 20))
      9. Signal Status (custom - "BUY" if MA9 > MA20 else "WAIT")

      POPULATION METHOD:
      - Manually add stocks from scanner results
      - Or use pre-market gappers from external source
      - Keep max 5 stocks (focus = edge)

PART 2: CUSTOM SCANNER COLUMNS (DETAILED)
========================================

To add custom columns to your scanner, follow these steps:

1. IN STOCK HACKER → COLUMNS
   - Click gear icon (⚙) in scanner
   - Select "Customize..."
   - Click "+ Add Column"

COLUMN 1: BUY SIGNAL
---------------------
Name: BuySignal
ThinkScript Code:
```
# Shows 1 if buy signal active, 0 otherwise
def MA_Fast = SimpleMovingAvg(close, 9);
def MA_Slow = SimpleMovingAvg(close, 20);
def bullishCross = MA_Fast[1] <= MA_Slow[1] and MA_Fast > MA_Slow;
def isBullish = close > open;
def hasLowerShadow = (Min(open, close) - low) > AbsValue(close - open) * 0.5;

plot signal = bullishCross and isBullish and hasLowerShadow;
```

COLUMN 2: QUALITY SCORE
-----------------------
Name: Quality
ThinkScript Code:
```
# Quality score 0-15
def MA_Fast = SimpleMovingAvg(close, 9);
def MA_Slow = SimpleMovingAvg(close, 20);
def today = GetYYYYMMDD();
def isNewDay = today != today[1];
def todayOpen = if isNewDay then open else todayOpen[1];
def pctChange = if todayOpen > 0 then ((close - todayOpen) / todayOpen) * 100 else 0;
def avgVol = Average(volume, 30);
def relVol = if avgVol > 0 then volume / avgVol else 0;
def hasLowerShadow = (Min(open, close) - low) > AbsValue(close - open) * 0.5;

plot score =
    (if close >= 1 and close <= 20 then 3 else 0) +
    (if relVol >= 5 then 2 else if relVol >= 3 then 1 else 0) +
    (if pctChange >= 20 then 2 else if pctChange >= 10 then 1 else 0) +
    (if hasLowerShadow then 2 else 0) +
    (if MA_Slow > MA_Slow[1] then 2 else 0) +
    (if MA_Fast > MA_Slow then 2 else 0);
```

COLUMN 3: PERCENT CHANGE
-------------------------
Name: %Change
ThinkScript Code:
```
def today = GetYYYYMMDD();
def isNewDay = today != today[1];
def todayOpen = if isNewDay then open else todayOpen[1];
plot pctChange = if todayOpen > 0 then ((close - todayOpen) / todayOpen) * 100 else 0;
```

COLUMN 4: RELATIVE VOLUME
--------------------------
Name: RelVol
ThinkScript Code:
```
def avgVol = Average(volume, 30);
plot relVol = if avgVol > 0 then Round(volume / avgVol, 1) else 0;
```

COLUMN 5: RISK/REWARD
---------------------
Name: RR
ThinkScript Code:
```
def swingLow = Lowest(low, 10);
def lowerShadow = Min(open, close) - low;
def stopLoss = Min(swingLow, low - lowerShadow);
def risk = close - stopLoss;
def target = close + (risk * 2);
plot rr = if risk > 0 then Round((target - close) / risk, 1) else 0;
```

COLUMN 6: BARS IN PULLBACK
---------------------------
Name: Bars
ThinkScript Code:
```
def MA_Fast = SimpleMovingAvg(close, 9);
def MA_Slow = SimpleMovingAvg(close, 20);
def bearishCross = MA_Fast[1] >= MA_Slow[1] and MA_Fast < MA_Slow;

def barsInPullback;
if bearishCross {
    barsInPullback = 1;
} else if barsInPullback[1] > 0 and MA_Fast < MA_Slow {
    barsInPullback = barsInPullback[1] + 1;
} else {
    barsInPullback = 0;
}

plot bars = barsInPullback;
```

COLUMN 7: ENTRY PRICE
---------------------
Name: Entry
ThinkScript Code:
```
def MA_Fast = SimpleMovingAvg(close, 9);
def MA_Slow = SimpleMovingAvg(close, 20);
def bullishCross = MA_Fast[1] <= MA_Slow[1] and MA_Fast > MA_Slow;

plot entry = if bullishCross then close else Double.NaN;
```

COLUMN 8: STOP LOSS PRICE
-------------------------
Name: Stop
ThinkScript Code:
```
def swingLow = Lowest(low, 10);
def lowerShadow = Min(open, close) - low;
def stopLoss = Min(swingLow, low - lowerShadow);

def MA_Fast = SimpleMovingAvg(close, 9);
def MA_Slow = SimpleMovingAvg(close, 20);
def bullishCross = MA_Fast[1] <= MA_Slow[1] and MA_Fast > MA_Slow;

plot stop = if bullishCross then stopLoss else Double.NaN;
```

========================================
TROUBLESHOOTING
========================================

PROBLEM: Scanner not showing results
FIX:
- Check timeframe is 5-min (not Daily)
- Verify code has no errors
- Try reducing filters (lower minPercentGain to 5%)
- Check "Scan in: All Stocks" is selected

PROBLEM: Charts not linking
FIX:
- Click chain link icon on each chart
- Make sure all are same color
- Restart TOS if still broken

PROBLEM: Alerts not triggering
FIX:
- Go to Setup → Application Settings → Notifications
- Enable "Desktop Alerts"
- Enable "Sounds"
- Check phone has TOS mobile app with notifications ON

PROBLEM: Scanner slow/laggy
FIX:
- Increase auto-refresh to 60 seconds
- Reduce max results to 25
- Close other programs (free up RAM)
- Check internet speed

PROBLEM: Too many false signals
FIX:
- Increase qualityScore minimum to 12+
- Increase minPercentGain to 15%
- Increase minRelativeVolume to 5x
- Only trade first hour (9:30-10:30 AM)
